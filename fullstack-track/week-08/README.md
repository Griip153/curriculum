# Week 8 — Project Week & Showcase

Build and deploy a complete REST API of your own — full-stack interns add a React frontend on top. Ideas: a church contributions API, an appointment booking API for a clinic, a student results portal, an inventory API for a local shop. Requirements: MongoDB Atlas with at least 3 related models, full CRUD, JWT auth with ownership permissions, validation and error handling, filtering + pagination, deployed live on Render, documented endpoints in the README, daily-report PRs all merged.
