# Day 2 — HTML & Semantic HTML

## Objective
Structure a real web page the way professionals do — with meaning, not just <div> everywhere.

## Concepts
Tags, elements, attributes; headings, paragraphs, lists, links, images, tables, forms; semantic tags (header, nav, main, section, article, footer) and why they matter for SEO and accessibility.

- "Why & When to use Semantic HTML" — Kevin Powell

## Task of the day
Build a personal profile page (about you, your goals, a photo, links) using at least 8 semantic tags and one form. Push to GitHub.
