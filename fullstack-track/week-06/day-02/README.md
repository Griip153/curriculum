# Day 22 — Validation & Error Handling Done Right

## Objective
APIs fail all the time — make yours fail clearly and safely.

## Concepts
Request validation (express-validator or Joi); Mongoose validation errors; try/catch patterns and async handlers; consistent JSON error responses; never leaking stack traces.

## Watch before the session
- Web Dev Simplified — Express error handling video
- "express-validator" or "Joi" tutorial — Traversy / Net Ninja
- Your own API from yesterday — break it on purpose and read every error

## Task of the day
Add validation to every write endpoint and a global error handler returning consistent JSON. Prove it in Postman with 5 deliberately bad requests.
