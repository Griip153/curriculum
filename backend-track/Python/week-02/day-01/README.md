# Day 5 — Asynchronous Python (heavy day)

## Objective
Master the concept every backend developer lives inside: code that waits without
blocking.

## Concepts
Synchronous vs asynchronous code; `async`/`await`; the event loop (conceptually);
calling a public API with `httpx`; error handling with `try`/`except`.
