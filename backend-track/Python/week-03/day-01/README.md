# Day 9 — SQL & Relational Databases (heavy day)

## Objective
Learn to think in tables and rows, and get comfortable writing SQL by hand before any
Python touches it.

## Concepts
Relational databases vs. the JSON-file storage you've used so far; tables, rows,
columns; primary keys; `SELECT`, `INSERT`, `UPDATE`, `DELETE`; `WHERE`, `ORDER BY`,
`JOIN`; SQLite as a zero-setup way to practice.

## Watch before the session
- "SQL Tutorial for Beginners" — freeCodeCamp
- "SQL Crash Course" — Traversy Media
- "SQLite in 100 Seconds" — Fireship

## Task of the day
Create a `library.db` SQLite database, create a `books` table and a `borrowers`
table, insert 10 books, and complete 10 query exercises given in class. Full
step-by-step instructions are in `LESSON.md`.
