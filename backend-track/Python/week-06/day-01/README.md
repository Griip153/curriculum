# Day 21 — Python Type Hints I — The Type System (heavy day)

## Objective
Write Python the way a professional team does: every function's inputs and outputs
declared, checked automatically, and self-documenting.

## Concepts
Why type hints exist; basic types (`str`, `int`, `float`, `bool`); `list[...]`,
`dict[...]`, `tuple[...]`; `Optional`/`| None`; typing function signatures; `mypy` for
static checking.

## Watch before the session
- "Python Type Hints" — mCoding or ArjanCodes
- "Type Checking Python with mypy" — Tech With Tim
- Real Python — "Python Type Checking" guide (intro sections)

## Task of the day
Take a folder of 15 deliberately untyped utility functions and add full, correct type
hints to every one, then run `mypy` until it reports zero errors. Full step-by-step
instructions and the first 3 fully solved are in `LESSON.md`.
