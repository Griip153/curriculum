# Backend Track — Python Foundations → Professional Backend with FastAPI (8 weeks)

One folder per week, one folder per day. Each day's `README.md` tells you the
objective, what to watch before the session, and the task of the day. Most days also
have a `LESSON.md` — a full, step-by-step, ground-level walkthrough of the day's
concepts, written for someone who has genuinely never programmed before. Read
`LESSON.md` *slowly*, typing every example yourself, before you touch the assignment.

- **Week 1** — Tools & The Python Language
- **Week 2** — Async Python & Into FastAPI
- **Week 3** — SQL, SQLAlchemy & Your First Real API
- **Week 4** — Project Week & Showcase
- **Week 5** — Authentication & Authorization
- **Week 6** — Type Hints & Pydantic In Depth
- **Week 7** — Production-Grade
- **Week 8** — Project Week & Showcase

**The rhythm:** watch the resources *before* the session → read `LESSON.md` → build
the task *during* the session → submit your daily report (in the `daily-reports` repo)
*the same day*.

## Before Week 1 — what you need installed

You only need three things to start. Full step-by-step instructions are in
`week-01/day-01/LESSON.md`, but here's the shopping list:

1. **Python 3.11 or newer** — the language itself.
2. **VS Code** — the editor you'll write everything in.
3. **Git** — the tool that saves versions of your code and pushes them to GitHub.

You do **not** need to know anything about programming yet. Week 1, Day 2 assumes you
have never written a line of code in your life.

## How this track is organised

- **Weeks 1, 2, 3, 5, 6, 7** teach new material. Every day has a `README.md` (the
  quick summary) and a `LESSON.md` (the full lesson, meant to be read top to bottom).
- **Weeks 4 and 8** are project weeks — no new material, just you applying everything
  you've learned so far to build and ship a complete API of your own.
- Every taught day that has hands-on coding practice also has an `exercises/` folder
  with starter files. Files marked "SOLVED" were built together in the lesson; files
  with `# TODO` comments are yours to finish, using the exact same approach.

## A note on tools

This track uses **FastAPI** (the framework), **Pydantic** (data validation),
**SQLAlchemy** (talking to a real database), and plain **SQLite/Postgres** (the
database itself) — the same category of tools a professional Python backend team uses
today. Nothing here is a "toy" version of the real thing; it's the real thing, taught
from the ground up.
