# Week 8 — Project Week & Showcase

Build and deploy a production-grade REST API — in TypeScript if you are up to it (strongly encouraged). Ideas: a clinic appointment API, a church management API, a school results API, an e-commerce backend for a local shop. Requirements: MongoDB Atlas with 3+ related models, JWT auth with ownership and roles, validation everywhere, filtering + pagination + one aggregation endpoint, file upload, 12+ passing tests, security middleware, Swagger docs, deployed live on Render, README with setup instructions, daily-report PRs all merged.
