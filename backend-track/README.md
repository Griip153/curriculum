# Backend Track — JavaScript & Node Foundations → Professional Backend & TypeScript (8 weeks)

One folder per week, one folder per day. Each day's README tells you the objective, what to watch before the session, and the task of the day.

- **Week 1** — Tools & The Language
- **Week 2** — Async JavaScript & Into Express
- **Week 3** — MongoDB & Your First Real API
- **Week 4** — Project Week & Showcase
- **Week 5** — Authentication & Authorization
- **Week 6** — TypeScript
- **Week 7** — Production-Grade
- **Week 8** — Project Week & Showcase

**The rhythm:** watch the resources *before* the session → build the task *during* the session → submit your daily report (in the `daily-reports` repo) *the same day*.
