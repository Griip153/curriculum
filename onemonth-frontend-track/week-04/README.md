# Week 4 — Project Week & Showcase

Teaching slows down. This week you build a complete project of your own and present it at the Showcase. Choose something that solves a small real problem — ideas: a church group dues tracker, a campus food menu app, a local business landing page with a working contact form, a quiz app for GCE revision. Requirements: built with React (or HTML/CSS/JS + Bootstrap if you joined late), responsive, on GitHub with a README, and deployed (Vercel or Netlify).
