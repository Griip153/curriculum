# Day 18 — Models, ORM, Migrations & Admin (heavy day)

## Objective
Define data in Python and let Django build the database — and see how your SQL knowledge maps onto the ORM.

## Concepts
Models and field types; makemigrations/migrate; ORM CRUD in the shell (and the SQL it generates); ForeignKey and ManyToMany; the admin site and customisation.

## Watch before the session
- Corey Schafer — Django series, database/models episodes
- Dennis Ivy — models and admin videos
- Official docs — "Models" page (skim, bookmark)

## Task of the day
Rebuild your Week 4 project’s data model in Django (e.g. contributions or inventory), register everything in admin, seed 15 records, and reproduce 10 of your SQL queries with the ORM.
