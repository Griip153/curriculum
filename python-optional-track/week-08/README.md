# Week 8 — Project Week & Showcase

Build and deploy a production-grade REST API of your own. Ideas: a clinic appointment API, a church management API (members, groups, contributions), a school results API, an inventory API for a local business. Requirements: PostgreSQL, at least 4 related models, full CRUD, JWT auth with object-level permissions, search + filtering + pagination, at least one file/image upload, 10+ passing tests, Swagger docs, deployed live on Render, README with setup instructions.
