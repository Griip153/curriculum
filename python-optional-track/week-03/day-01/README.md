# Day 9 — SQL Fundamentals (heavy day)

## Objective
Learn the language of databases — the skill under every ORM you will ever use.

## Concepts
Tables, rows, columns; CREATE TABLE and data types; INSERT, SELECT, WHERE, ORDER BY; UPDATE and DELETE; JOINs between two tables; primary and foreign keys.
